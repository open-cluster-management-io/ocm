Metric source notes
  • API-server CPU, memory, request rate and mean request latency are scraped from each kubeconfig API server’s /metrics.
  • etcd, Kine and PostgreSQL container CPU/memory require Prometheus URLs and matching container metrics.
  • Unavailable metrics stay blank; the dashboard never substitutes guessed live values.
  • ManagedClusters use the issued simulator-agent client certificate. If hub CSR approval/signing is unavailable, the registration remains pending; the simulator does not approve its own CSR.
  • This models registration resources, leases and work-agent API calls—not the full Klusterlet deployment or an application runtime on a spoke.
